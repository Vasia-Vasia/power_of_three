Реализуйте функцию is_power_of_three(), которая определяет, является ли переданное число натуральной степенью тройки. Например:

Число 27 — это третья степень: 3 ** 3  
А число 81 — это четвертая: 3 ** 4  

__Примеры:__

is_power_of_three(3)  # True  
is_power_of_three(2)  # False  
is_power_of_three(9)  # True
